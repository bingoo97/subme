# Verified cash renewal expiry-base deployment

Both demo.subme.pro and dashboard.subme.pro run application revision 7a7f952 (previous runtime 3be399c). Three allowlisted files were extracted from the committed revision: admin/bootstrap.php, admin/index.php and assets/js/admin.js. No migrations, local configuration or business records were transferred.

Deferred paid renewals now calculate their target when actually fulfilled: from the existing expiry when still valid, otherwise from the fulfilment time. The stored paid package duration is retained even if the current product duration changes. Automatic form previews are identified separately so a stale preview cannot shorten a delayed renewal; manually edited expiry overrides remain supported. Existing idempotent cash receipts, renewal application and ledger keys prevent duplicate credit, debit or extra periods.

The same application revision previously passed 67 complete page renders without PHP warnings.

Neither site had active cash subscriptions missing expiry dates.
